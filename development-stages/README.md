# 단계별 결과물 코드

동아리 활동 보고서에 복사할 수 있도록 App.tsx 전체 코드를 단계별로 정리했습니다.

| 단계 | 파일 | 기능 범위 |
| --- | --- | --- |
| 1차 개선 | [01-stage1-App.tsx](01-stage1-App.tsx) | 로그인, 프로필 설정, 메인 메뉴, 방 생성·참가, 대기실 |
| 2차 개선 | [02-stage2-App.tsx](02-stage2-App.tsx) | 1차 기능 + 2·3인 경기, 모드·테마 투표, 선택·결과, 포인트 랭킹, 익명 설정 |
| 최종 | [03-final-App.tsx](03-final-App.tsx) | 2차 기능 + 일일 퀘스트, 개인 경기·라운드 기록 |

## 코드의 출처와 사용 범위

1차와 2차는 보고서의 개선 과정을 설명하기 위해 기능별로 재구성한 중간본이며 실제 과거 커밋의 원본이 아닙니다. 최종 코드는 feature/playable-arena 브랜치의 구현(커밋 5f14faf01df253b7a7ad9ee91b8cd5848ffaa6a0)을 바탕으로 합니다.

각 파일은 App.tsx 전체이며 앱 전체 프로젝트를 한 파일로 합친 것은 아닙니다. 실행하려면 해당 구현의 React Router, lib/useArena, lib/gameApi, lib/firebase, domain/game, styles.css, Firebase 서버 함수와 보안 규칙 등도 함께 필요합니다. 현재 main 브랜치의 초기 구현에 이 파일만 덮어써서는 실행되지 않을 수 있습니다.

이 폴더는 보고서용 코드 보관용입니다. 이 업로드로 실제 앱이나 Firebase 배포 상태가 변경되지는 않습니다.
